# RecruitFlow

## Services
- Eureka Server
- API Gateway
- Auth Service
- Job Service
- Profile Service

## Tech Stack
- Java 21
- Spring Boot
- Spring Cloud Eureka
- Spring Data JPA
- PostgreSQL
- Maven

## Running the Project

1. Start PostgreSQL
2. Start Eureka Server
3. Start API Gateway
4. Start Auth Service
5. Start Job Service
6. Start Profile Service
